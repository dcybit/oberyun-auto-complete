# 欧倍尔自动完成课程

欧倍尔虚拟仿真云平台（oberyun.com）课程与考试自动完成工具。

## 功能

- 自动遍历课程所有章节资源（视频/PDF/文档）并标记为已完成
- 考试自动答题（安全通识-文科类，100 题答案库，实测 100 分）
- 启动器每 3 秒轮询 oberyun 标签页，**URL 变化时自动重新注入**（支持 SPA 路由跳转后脚本依然生效）
- 页面右下角可视化状态浮窗，无需打开控制台即可查看进度
- 考试入口页点击一次后耐心等待抽题（1~3 分钟），期间绝不重复点击；发现抽题 loading 则延长等待
- 交卷自动点击确认弹窗（兼容 Ant Design 按钮文案中间插空格），读取真实成绩而非误匹配「满分：100分」
- API 失败自动重试（502/503/504 等临时错误）

## 快速使用

1. 双击 `OberyunAutoComplete.exe`
2. 自动打开浏览器并导航到欧倍尔平台，登录账号
3. 脚本自动开始处理课程与考试，**页面右下角**会显示运行进度浮窗

## 文件说明

| 文件 | 说明 |
|------|------|
| `OberyunAutoComplete.exe` | 启动器（.NET 8 single-file，v3.2），启动浏览器并按 URL 变化重新注入脚本 |
| `oberyun-auto.js` | 自动完成脚本（课程标记完成 + 考试答题）v8.5 |
| `exam-answers.txt` | 考试答案库（已实测 100 分验证） |
| `oberyun-build/Program.cs` | 启动器源码（v3.2） |
| `oberyun-build/OberyunAuto.csproj` | 启动器项目文件 |

## 构建启动器

```bash
cd oberyun-build
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true -o ..
```

构建产物 `OberyunAutoComplete.exe` 输出到项目根目录。

## 版本历史

### v8.5 (脚本) / v3.2 (启动器)
- **修复考试入口"点了没反应"**：选择器 `[class*=btn]` 先命中包裹按钮的 `<div class="btn">`（无点击事件），改为优先只取真实可点击元素（button/a/.ant-btn）
- **修复交卷未真正提交**：Ant Design 两字按钮在文案中间插入空格（「确 定」），正则 `^(确定\|…)$` 匹配不到，改为去掉所有空白后匹配并轮询等待弹窗出现
- **修复成绩误报 100 分**：原正则 `/(\d+)\s*分/` 匹配到页面上的「本试卷满分：100分」，改为必须匹配「考试成绩…xx分」
- **启动器 v3.2**：注入去重键从 `tabId` 改为 `tabId + url`，SPA 路由跳转后新文档会自动重新注入脚本（v8.4 已改为点一次后耐心等待抽题，v3.2 配合让页面跳转后脚本依然生效）
- 启动器每 3 秒轮询 oberyun 标签页；`__OberyunAutoRunning` 防重入，重复注入是安全的空操作

### v8.4 (脚本)
- **修复反复点击「开始答题」导致永远进不去考试**：点「开始答题」后平台要"抽题" 1~3 分钟才跳转考试页，旧逻辑 24s 就重新点击，导致反复重新抽题浪费考次。现改为点一次后耐心等待 240s（检测到抽题 loading 则延长到 420s），期间绝不重复点击
- 检测到抽题进度（URL 含 `texam/testPaper` / 出现 loading / 出现「抽题」文本）时延长等待时间
- 等待过程每 15s 输出进度，失败时输出 frame 诊断信息

### v8.3 (脚本)
- 修复考试无法自动进入：入口页支持「开始答题/开始考试/进入考试/继续答题」多种按钮文案，并自动点击确认弹窗
- 考试题目可能位于 iframe 内：所有查找/点击改为跨 frame 递归遍历
- 进入考试失败自动重试 3 轮；也可手动点「开始答题」后由脚本接管答题
- 考试页识别不再只依赖 URL，同时检测 `.paperContent` DOM
- 章节资源考试节点识别增强（类型/标题多字段，兼容中文「考试/试卷」）
- 新增 frame 诊断日志（radio/checkbox/paper 数量），便于定位题目所在框架

### v8.2 (脚本)
- 登录阶段循环检测课程：未登录或暂未取到课程时持续轮询，不再提前结束
- 自动识别登录页（URL 含 `login` 或存在密码输入框），在浮窗提示"请输入账号密码登录"
- 登录完成后自动继续处理课程，无需手动重新运行脚本
- `Vue $http` 未就绪时无限等待（原为 15 次后退出）
- 轮询期间静默 API 日志，避免浮窗刷屏

### v8.1 (脚本) / v3.1 (启动器)
- 修复课程列表 API 502 等临时错误，增加自动重试机制（每路径最多 3 次，间隔 3 秒）
- 修复启动器 CDP 注入：`awaitPromise=false` 避免超时、按 id 匹配响应、注入后验证脚本运行状态

### v8.0 (脚本) / v3.0 (启动器)
- 修复课程列表 API 路径（正确路径带 `/V2/` 前缀，自动回退尝试）
- 添加页面右下角可视化状态浮窗
- 增强 `getHttp()` 鲁棒性
- 考试打开方式从 `window.open` 改为当前页导航，避免会话丢失

## 考试答题原理

- 通过 CDP 向浏览器注入 JS，按 DOM 顺序点击 radio/checkbox 选项
- 多选题每次点击间隔 600ms，避免 `saveAnswers` 请求乱序
- 交卷后自动读取成绩
